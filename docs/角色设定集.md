## 五、一致性出图流程（铁律）

1. **第一批**：只出 3 张立绘（`prompts\ep01\00-角色立绘.md`）→ **用户逐张过目确认形象** → 确认后立绘冻结为参考图；随后追加三视图批次（ref-*-tv.png，正/侧/背同造型），一并作为场景图参考图。
2. **第二批**：场景图 = 画风锁 + 场景提示词 + **冻结锚点短语（roles 自动注入）** + 参考图（即梦参考图功能 / MJ `--cref --cw 80` / Gemini `-r` 多图），服装色块和标志物不许变。
3. 蒙太奇四图刻意**无主角脸**（背影/剪影/物品特写），把一致性风险集中在 5 张有脸图上（s03/s04/s05/s12/s13；s04/s05 还被 s06–s08 复用运镜，同图多镜头 = 天然一致）。
4. **三道机器/人眼关卡**：
   - V11 机器验证：从立绘实测签名色（紫袍/青袍等），每张带角色图必须出现（防止袍色漂移；人脸/体态漂移由锚点短语 + 参考图兜住，机器检查到不了这个粒度）
   - 拼图验收：批次完成后自动生成 `output\contact-sheet.jpg`（3 立绘 + 10 场景图同格），**用户一眼横向对比**再放行渲染
   - 成片抽帧：用户审片时对照本表锚点
5. 出图不合格的返工标准：换发型/服装颜色、标志物缺失、脸型不符、画面出现文字、比例不符 → 按提示词包重出（幂等覆盖，重跑不重复花钱）。
